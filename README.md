# 👨🏻‍💻Anildo Gomes

**`Consultor`**  **`Professor`** **`Desenvolvedor`**

Muitos me conhecem pela atuação comercial no setor automotivo ou pela minha entrega em sala de aula como professor de administração. Mas, nos bastidores, venho cultivando uma paixão que me desafia diariamente: a tecnologia.

Minha trajetória sempre foi guiada pela curiosidade. Da Pedagogia à Análise de Sistemas, entendi que educar e programar têm muito em comum: ambos tratam de construir estruturas que resolvem problemas e transformam realidades.

Hoje, meu tempo livre é dedicado ao código. Seja explorando o ecossistema React, estilizando com Tailwind ou estruturando dados com Python e PostgreSQL, encontrei no desenvolvimento de software uma nova forma de criar e inovar. 💻

Não é sobre mudar quem eu sou, mas sobre somar quem estou me tornando. Do asfalto das estradas que percorro de moto à lógica do terminal, o objetivo é o mesmo: nunca parar de explorar.

Vamos juntos para o próximo commit? 🚀
